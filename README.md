# Мотивация теориялары — 3D-презентация

Интерактивная презентация (10 слайдов, казахский язык) о четырёх теориях мотивации:
Маслоу, Герцберг, МакКлелланд, Врум. Стек: **Next.js 16 + React 19 + three.js
(@react-three/fiber, @react-three/drei)**.

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
```

Production:

```bash
npm run build
npm start
```

## Управление

| Действие | Как |
|---|---|
| Следующий / предыдущий слайд | `→` `↓` `Space` `Enter` `PageDown` / `←` `↑` `Backspace` `PageUp`, кнопки внизу, свайп |
| Перейти к слайду N | клавиши `1`–`9`, `0` = 10-й; точки внизу; ссылка `/#N` |
| Первый / последний | `Home` / `End` |
| Полный экран | кнопка «Толық экран» справа сверху, кнопка «Толық экранда бастау» на титуле, клавиша `F` |
| Пирамида Маслоу (слайд 4) | наведение на уровень в списке или клик по слою 3D-пирамиды подсвечивает уровень |

В полноэкранном режиме панель управления скрывается через 3 с бездействия мыши.

## Слайды

1. Титул — 4 спикера с портретами, кнопки старта
2. Шолу — четыре теории на одном экране
3. Маслоу — портрет, суть теории
4. Пирамида Маслоу — интерактивная 3D-пирамида (5 уровней)
5. Герцберг — портрет, суть теории
6. Два фактора — гигиенические vs мотивационные
7. МакКлелланд — три потребности (nAch / nPow / nAff), 3D-орбиты
8. Врум — портрет, суть теории
9. Формула ожидания — Мотивация = E × I × V, 3D-цепочка
10. Қорытынды — сравнительная таблица, «Назарларыңызға рахмет!»

## Структура

```
src/
  app/            layout, page, globals.css
  components/
    Presentation.tsx   состояние, навигация, fullscreen, клавиатура
    three/Scene.tsx    R3F-сцена: пирамида, кольца, орбиты, цепочка, фон
    slides/            компоненты 10 слайдов
  data/slides.ts       весь текст презентации (правится здесь)
public/photos/         портреты теоретиков
```
